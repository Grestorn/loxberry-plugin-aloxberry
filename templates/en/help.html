Control your Loxone home by voice through Amazon Alexa. You decide exactly which Loxone controls Alexa can see and what it may do with them.

Quick start

  1. Setup tab → Start the daemon, then generate a single-use pair code (valid 10 min).
  2. In the Alexa app: enable the "Aloxberry" skill and start account linking; paste the pair code when asked. No Loxone credentials ever leave your LoxBerry.
  3. Devices tab → pick the Loxone controls to expose, set friendly names/capabilities, then Save.
  4. Say "Alexa, discover my devices" to pick up the changes.

The three tabs

  • Devices — choose which Loxone controls Alexa sees and how they map (nothing is exposed automatically).
  • Setup — daemon start/stop, status, pair code, runtime settings, and the "kill all pairings" switch.
  • Logs — per-daemon-start log sessions; set the log level in LoxBerry and restart the daemon to apply.
⚙ Safety: the master switch and the "pause while a Virtual Status is on" gate (Devices tab) cut Alexa→Miniserver commands instantly. The cloud relay can neither read nor forge your commands (end-to-end HMAC).

Troubleshooting

  • No catalogue / no devices: daemon not running or not connected to the Miniserver — check the Setup tab and the Logs.
  • Alexa can't find devices: re-run "Alexa, discover my devices" after saving on the Devices tab.
  • A device Alexa keeps bringing back: if you deleted the control in Loxone Config, the entry survives on the Devices tab marked Missing in Loxone. Aloxberry stops reporting it to Alexa, but Alexa keeps a device until you delete it in the Alexa app — do both: remove it here (and Save), and delete it there.
  • Link stopped working: the identity may have been reset (kill-pairings) — re-link from the Alexa app.
⚠ Public beta: expect occasional breaking changes and re-linking between versions. Do not rely on it for safety- or access-critical functions.
